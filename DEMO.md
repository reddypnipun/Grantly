# DEMO.md — 3-minute pitch script

## Pitch (3 min)
1. Problem (30s): scholarships are scattered, eligibility confusing, deadlines missed, applications repetitive, no progress visibility.
2. Solution (30s): Grantly — tell us about yourself once; we tell you exactly which you can win, why, what's missing, what to do next.
3. Demo (90s):
   - Landing → "Try with a sample student" → dashboard populated.
   - Discover: ranked feed, NL search "engineering scholarships for women under 2 hours", filter, compare.
   - Detail: eligibility breakdown, trust panel.
   - Start application → tracker Kanban, drag card, Move-to menu, checklist.
   - Calendar month view + .ics export; notification bell.
   - Vault: essay with outline generator + reuse suggestions.
   - What-if simulator: move GPA slider, matches update live.
   - Goals: funding coverage progress.
4. Impact (30s): mobile-first, accessible, offline, no backend, sample data labeled.

## Click-by-click demo path
1. Open app → landing.
2. Click "Try with a sample student" → onboarding?sample=1 → dashboard.
3. Dashboard: point out funding, closing this week, next best action.
4. Discover → type "engineering scholarships for women under 2 hours" → show filtered.
5. Open a scholarship → show eligibility breakdown + trust panel.
6. Click Start application → tracker.
7. Drag card across columns; show checklist.
8. Calendar → month view → agenda → download .ics.
9. Vault → create essay → outline generator → reuse suggestions.
10. What-if → adjust GPA → animated update.
11. Goals → show coverage.
12. Mobile: resize to 375px, show bottom nav.
